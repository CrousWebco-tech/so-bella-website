## 🎨 Customization Areas

### Colors
Edit `tailwind.config.ts` to change the luxury palette:
- Blush pink (#f5e6e0)
- Nude beige (#e8d4c4)
- Gold accents (#d4af7a)
- Black (#1a1a1a)
- White (#faf9f7)

### Fonts
Update Google Font imports in `app/globals.css`:
- Currently: Playfair Display (serif), Montserrat (sans)
- Change to any Google Font

### Services
Edit the SERVICES array in `lib/constants.ts`:
- Add, remove, or modify services
- Update descriptions and icons
- Change pricing

### Images
Replace placeholders:
- Logo: `public/images/logo.png`
- Hero: `public/images/hero.jpg`
- Owner: `public/images/owner.jpg`
- Gallery: Add to `public/images/`

## 🐛 Troubleshooting

### Won't start locally?
```bash
rm -rf node_modules
npm install
npm run dev
```

### Build errors on Vercel?
- Check Vercel deployment logs
- Run `npm run build` locally
- Check for TypeScript errors

### Environment variables not working?
- Verify `.env.local` exists
- Verify variables are added to Vercel
- Restart dev server after changes

### Database not connecting?
- Verify Supabase URL and key
- Check they're in `.env.local`
- Verify Supabase tables exist

For more help, see `MAINTENANCE.md` troubleshooting section.

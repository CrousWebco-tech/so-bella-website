## 📞 If Client Has Issues Later

Common problems & quick fixes:

**"I can't log in"**
- Check password is correct (case-sensitive)
- Try a different browser
- Clear browser cache

**"My changes didn't save"**
- Make sure you clicked "Save Changes"
- Check for error message
- Try again

**"The website looks broken"**
- Clear browser cache (Ctrl+Shift+Delete or Cmd+Shift+Delete)
- Try a different browser
- Take a screenshot and send to developer

**"I want to change the design"**
- Contact the developer (may have a fee)
- Design is fixed by default
